# Conformidade IBS/CBS

Projeto para acompanhamento e análise da conformidade tributária relacionada ao **IBS (Imposto sobre Bens e Serviços)** e à **CBS (Contribuição sobre Bens e Serviços)**, tributos criados pela Reforma Tributária (Emenda Constitucional nº 132/2023).

## Sobre o projeto

Este repositório reúne documentos, planilhas e demais arquivos utilizados para:

- Verificar a conformidade da empresa com as novas obrigações do IBS/CBS;
- Organizar e visualizar dados relacionados à apuração e transição tributária;
- Servir como base de consulta e histórico do processo de adequação à reforma.

## Conteúdo

Os arquivos de trabalho (incluindo um arquivo `.zip` com os materiais para visualização) serão adicionados diretamente neste repositório.

## Como usar

1. Baixe ou extraia o arquivo `.zip` disponibilizado no repositório.
2. Consulte os arquivos conforme a necessidade (planilhas, relatórios, documentos de apoio).
3. Atualizações e novos materiais serão versionados aqui ao longo do processo de conformidade.
